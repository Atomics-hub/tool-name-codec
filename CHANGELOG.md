# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## 0.1.0 - 2026-08-30

- Add whole-catalog tool-name compilation for MCP, OpenAI, Anthropic, and Gemini profiles.
- Add deterministic readable and stateless full-digest allocation modes.
- Add serialized reverse maps, historical tombstones, reserved-name handling, and migration planning.
- Add bounded input and manifest validation with typed errors.
- Add ESM, CommonJS, browser, worker, Bun, Deno, and Node support with zero runtime dependencies.
